# DLMF Documentation Index

Source site: [NIST Digital Library of Mathematical Functions](https://dlmf.nist.gov/)

Current source version observed: 1.2.7, release date 2026-06-15.

This folder documents DLMF page by page. Each row corresponds to one browsed DLMF page and points to one Markdown file. Progress is intentionally checkpointed here so later steps can continue without re-browsing completed pages.

## Context

The DLMF is the NIST Digital Library of Mathematical Functions: a structured reference for special functions and the analytic, asymptotic, numerical, graphical, computational, and application material needed to use them responsibly. In this vault it should be treated as a source-faithful mathematical corpus: formulas, definitions, notation, provenance, and DLMF section boundaries are preserved before interpretation is added.

This makes DLMF complementary to the local [Mathematical Ontology](../Mathematical%20ontology/README.md). The ontology asks what kind of mathematical thing is present before asking how to calculate with it: structure, operation, representation, observation, invariant, projection, reference frame, equivalence class, or failure of translation. DLMF supplies the authoritative formulas and notation; the ontology supplies the typed semantic roles that help those formulas become navigable in Obsidian.

The same bridge points outward to [Machine Modelled Language](https://github.com/fountain-of-love/mml-machine-modelled-language) and its [Semantic Seed Vault](https://github.com/fountain-of-love/mml-machine-modelled-language#scientific-foundation-the-semantic-seed-vault). MML aims to represent governed concepts, aliases, semantic roles, and typed relations in a way that can become executable semantic infrastructure. The Seed Vault preserves human-readable concepts, claims, evidence, contradictions, provenance, and patterns. The DLMF corpus can serve as a mathematical seed source for that larger system, provided every extracted relation keeps its source URL, version metadata, formula identity, and mathematical type.

Practical reading model:

| Layer | Role in this vault |
|---|---|
| DLMF source pages | Authoritative reference layer for formulas, notation, definitions, identities, and section provenance. |
| Local DLMF Markdown | Obsidian-readable page-per-source-page corpus with formulas rendered and source metadata retained. |
| Mathematical ontology | Typed interpretation layer for structures, operations, observations, invariants, projections, dimensions, and equivalence. |
| MML | Candidate execution layer for governed concepts, senses, aliases, and typed semantic relations. |
| Semantic Seed Vault | Durable knowledge layer for reviewed mathematical seeds, evidence, provenance, contradictions, and reusable patterns. |
