# Notations

Source: [https://dlmf.nist.gov/not/](https://dlmf.nist.gov/not/)

Observed version: 1.2.7, release date 2026-06-15.

## Purpose

The Notations page is DLMF's alphabetical notation index. It lists symbols and forms used across the library and links them to their defining sections.

## Page Structure

- Alphabetic navigation including a symbol category.
- Entries include mathematical symbols, operators, interval notation, factorial variants, q-notation, matrix notation, special-function notation, and combinatorial symbols.
- Many entries link back to common notations in the Mathematical Introduction or to chapter-specific notation sections.

## Documentation Notes

This page is the best checkpoint for notation consistency. Later section pages should refer back here rather than repeating broad notation definitions unnecessarily.
