# List of Figures

Source: [https://dlmf.nist.gov/lof/](https://dlmf.nist.gov/lof/)

Observed version: 1.2.7, release date 2026-06-15.

## Purpose

The List of Figures gathers DLMF figures and graphics by chapter.

## Page Structure

- Entries are grouped by chapter.
- Figure entries include numbered references and captions.
- The list covers diagrams, branch cuts, graphs of functions, conformal maps, surfaces, zeros, and visualization material.

## Documentation Notes

This page is especially useful for locating visual explanations. During section-level documentation, figure-heavy sections should link back to this list when a visual summary is more helpful than formula-only notes.
