# Software Index

Source: [https://dlmf.nist.gov/software/](https://dlmf.nist.gov/software/)

Observed version: 1.2.7, release date 2026-06-15.

## Purpose

The Software Index cross-references available software for DLMF topics and points to software classifications and repositories.

## Page Structure

- Software Cross Index
- A Classification of Software
- Software Repositories

## Main Points

- The cross index is organized by DLMF chapter and computational topic.
- It distinguishes open source, book-associated, and commercial software.
- It records implementation language coverage such as C, Fortran, C++, Java, Python, Mathematica, and interactive systems.
- Repository references include ACM TOMS algorithms, Computer Physics Communications Program Library, netlib, and GAMS.

## Documentation Notes

This page should be used when section documentation reaches computation or software subsections. It provides the operational layer of the mathematical reference.
