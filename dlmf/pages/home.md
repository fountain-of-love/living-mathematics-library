# DLMF Homepage

Source: [https://dlmf.nist.gov/](https://dlmf.nist.gov/)

Observed version: 1.2.7, release date 2026-06-15.

## Purpose

The homepage is the entry point for the NIST Digital Library of Mathematical Functions. It gives project news, front matter, the 36 chapter table of contents, and links to supporting resources such as the bibliography, index, notations, figures, tables, software, and errata.

## Page Structure

- Project news lists recent DLMF updates, including version 1.2.7 dated 2026-06-15.
- Front matter links: Foreword, Preface, and Mathematical Introduction.
- Main mathematical content is organized into 36 numbered chapters.
- Supporting references include Bibliography, Index, Notations, List of Figures, List of Tables, Software, and Errata.
- Footer identifies NIST copyright coverage for 2010-2026 and links policy pages.

## Documentation Notes

This page is the root queue for the documentation pass. The top-level chapter order is being used as the first traversal order before descending into chapter sections.
