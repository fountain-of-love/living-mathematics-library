# Bibliography

Source: [https://dlmf.nist.gov/bib/](https://dlmf.nist.gov/bib/)

Observed version: 1.2.7, release date 2026-06-15.

## Purpose

The Bibliography is DLMF's alphabetical reference catalog. It lists books, papers, algorithms, software references, and historical sources cited across the DLMF.

## Page Structure

- Alphabetic navigation from A through Z.
- Each bibliographic item can include publication metadata, notes, external links, DLMF references, and encodings such as BibTeX.
- Entries are heavily cross-linked back to chapters, sections, equations, profiles, notations, and supporting pages.

## Documentation Notes

This page is a source map rather than a mathematical exposition page. Section-level notes should use it to trace provenance for formulas, algorithms, tables, and software.
