# Index

Source: [https://dlmf.nist.gov/idx/](https://dlmf.nist.gov/idx/)

Observed version: 1.2.7, release date 2026-06-15.

## Purpose

The Index is DLMF's alphabetical subject index. It maps mathematical concepts, function families, methods, applications, and named objects to chapters and sections.

## Page Structure

- Alphabetic navigation from A through Z.
- Entries range from compact pointers to nested topic trees.
- Many index items point to whole chapters, sections, subsections, equations, tables, or related index entries.

## Documentation Notes

This page is useful as a semantic routing layer. During deeper documentation, it can help discover cross-chapter relationships such as Airy functions in asymptotics, ship waves, and special-function transformations.
