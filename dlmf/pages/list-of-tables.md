# List of Tables

Source: [https://dlmf.nist.gov/lot/](https://dlmf.nist.gov/lot/)

Observed version: 1.2.7, release date 2026-06-15.

## Purpose

The List of Tables gathers DLMF tables by chapter.

## Page Structure

- Entries are grouped by chapter.
- Table entries include numbered references and captions.
- Early tables include transform tables, quadrature nodes and weights, recurrence coefficients, zeros, special values, and orthogonality data.

## Documentation Notes

This page is a practical locator for numerical constants, computational tables, and compact formula summaries.
