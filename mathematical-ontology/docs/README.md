# Mathematical Ontology Documentation

This directory contains the specifications and page contracts that make the mathematical ontology consistent, portable, and machine-readable without forcing every note into one enormous schema.

## Specifications

| Specification | Purpose |
|---|---|
| [Mathematical Design Principles](./mathematical-design-principles.md) | Defines the philosophy: dictionary as interface, one sentence first, portal links, honest absence, and human links backed by stable IDs. |
| [Knowledge Node Spec](./knowledge-node-spec.md) | Defines the minimal node contract, schema-term/entity distinction, stable IDs, and Markdown-as-source architecture. |
| [Universal Mathematical Knowledge-Node Schema](./universal-mathematical-knowledge-node-schema.md) | Defines one common node architecture, common knowledge-node types, typed relations, provenance, and validation rules. |
| [Mathematical Dictionary](./mathematical-dictionary.md) | Defines the compact interface ontology for canonical terms, relationship labels, stable links, and outward paths to deeper material. |
| [Mathematical Concept Spec](./mathematical-concept-spec.md) | Defines the page contract for stable mathematical concept notes using structured facts plus prose. |
| [Mathematical Formula Spec](./mathematical-formula-spec.md) | Defines the page contract for formulas, identities, transforms, recurrences, and expressions. |
| [Mathematical Theorem Spec](./mathematical-theorem-spec.md) | Defines the page contract for established mathematical claims, assumptions, proof status, and counterexample scope. |
| [Mathematical Conjecture Spec](./mathematical-conjecture-spec.md) | Defines the page contract for open mathematical claims, evidence, counterexamples, and proof status. |
| [Mathematical Proof Spec](./mathematical-proof-spec.md) | Defines the page contract for proofs, proof sketches, failed proofs, and proof audits. |
| [Mathematical Experiment Spec](./mathematical-experiment-spec.md) | Defines the page contract for computational, visual, numerical, and exploratory experiments. |
| [Mathematical Process](./mathematical-process.md) | Defines the design tensions, structured-facts/prose pattern, and repeatable knowledge-engineering operation. |
| [Mathematical Proof Run](./mathematical-proof-run.md) | Documents the standard five-item pre-scale audit for validating the specs on real notes before rollout. |
| [Proof Run 5](./proof-run-5.md) | Summarizes the completed five-item proof run and its scaling gate. |
| [Mathematical Worklist](./mathematical-worklist.md) | Tracks known mathematical objects separately from engineered knowledge objects. |
